# カードのバランスのデータ（v2.7）

調整案は書かない。数字だけ。カードの数値は変えていない。同じ結果を `npm run balance` で作り直せる（決まった種）。

## 調べ方

1. **計算で出す強さ**（1_calc.csv）：技の効果のデータから、サイコロ1回あたりの平均。「HP100を倒す平均ターン」は、持続ダメージ（あとから来る分）とばくだんも来るターンに数えて、決まった種で2万回くり返した平均（攻撃の回数。自分の気絶は数えない）。
2. **1対1の総当たり**（2_duel_matrix.csv・2_duel_rank.csv）：おてあげ全42種（ストーリー限定も）を1体どうし・アイテム・ベンチ・山札なしで、全部の組み合わせ（同じおてあげどうしも）を先攻・後攻を入れかえて1000試合ずつ。出来ることは攻撃だけなので CPU は使わない。先攻1ターン目は攻撃できない（ふつうのルール）。
3. **デッキに入れた時の効き目**（3_deck.csv）：基本のおてあげ（元祖パックの通常おてあげ）だけの基準のデッキ3つ（下）の1枚を、調べるカード1枚に入れかえ、基準のデッキと対戦。1枚につき 3デッキ × 668試合 ＝ 2004試合（先攻・後攻は半分ずつ）。**CPU は両方「つよい」**（「さいきょう」は1試合 約107秒かかり、この量では200時間以上かかるため。企画者の判断）。「勝率の差」は、入れかえたデッキの勝率から、入れかえない時（基準のデッキどうし）の勝率を、デッキごとに引いた平均（ポイント）。

| 基準のデッキ | 中身（各3枚） | 入れかえる1枚 | 入れかえない時の勝率（基準どうし） |
|---|---|---|---|
| A | むつあし・はさみ・よつあし・さんぼん・おてあげ | よつあし | 51.3% |
| B | はさみ・よつあし・さんぼん・おてあげ・みつめ | さんぼん | 50.3% |
| C | よんほん・むつあし・はさみ・よつあし・さんぼん | はさみ | 51.3% |

入れかえない時の勝率（3デッキ）は 51.0%。50% からのずれは、試合数による ぶれ（±1.1ポイントくらい）と先攻・後攻の差。

**総合の順位**：グループ（通常・スーパー・アイテム）の中で、1（HP×平均ダメージ。1回のダメージは HP100 の相手を倒す100までに切る。999 の技などがふくらまないように）・2（1対1の平均勝率）・3（デッキの勝率の差）それぞれの順位を 0（いちばん強い）〜1（いちばん弱い）の割合にして平均したもの。アイテムは3だけ。
